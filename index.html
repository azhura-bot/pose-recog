1. Buka Kamera

Browser membuka kamera, lalu MediaPipe Web memproses pose langsung di perangkat pengguna.

2. Deteksi Gerakan

Gestur seperti tangan kiri naik, tangan kanan naik, kedua tangan naik, atau jongkok diterjemahkan jadi aksi karakter.

3. Mainkan Game

Karena game dan pose engine berjalan di browser, orang lain bisa ikut main langsung dari link deploy.
